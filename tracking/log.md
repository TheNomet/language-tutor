# Learning Log

Human-readable journal. The tutor appends one short entry per session (newest at
the bottom). You can read this any time to see how far you've come. The structured
data lives in `progress.json`; this is the story.

Entry format:

```
## YYYY-MM-DD — Unit X.Y — <session type>
- Practiced: ...
- Went well: ...
- Struggled with: ...
- Brought back next time: ...
- Tutor note: ...
```
